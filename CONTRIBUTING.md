# Contributing

- `make test` runs vet and the unit tests. Keep it green.
- Conventional Commits, lowercase subjects: `feat:`, `fix:`, `docs:`.
- Comments explain why, in one or two lines.
- The CLI is used by agents more than by people: every command must work without a prompt and
  must accept `--json`.
- Security issues: email security@getnook.dev instead of opening an issue.
